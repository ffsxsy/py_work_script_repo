# AI 生成 / 修改 Python 后的验收

1. 阅读 `AGENTS.md` 与根目录 `pyproject.toml`。
2. 在仓库根**必须在终端实际执行**并通过 `AGENTS.md` §「Python 修改后必须执行」全部命令（顺序不可省略、禁止未跑通即声称完成）。
3. 类型注解与库调用须符合 `codegen-python-standards.md`（**当前 3.13 推荐写法**，非旧 `typing` 惯用法）。
4. 新功能须增加或更新 `tests/` 下 pytest；禁止只改实现不补测试（除非用户明确只要脚本、不要测试）。
5. 遗留代码尚未全绿时：至少保证**本次改动的 `.py` 文件**无新增 ruff / ty 问题；全仓清零可作为独立任务。

命令清单以 [AGENTS.md](../../AGENTS.md) 为唯一来源，勿在此重复维护。
